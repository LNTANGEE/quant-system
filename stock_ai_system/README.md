# 量化系统

这是一个使用 Python + Streamlit + SQLite + AKShare 开发的本地网页程序，用于辅助分析 A 股自选股、低位区间、做T条件、潜力股榜单、卖出后接回提醒和简化回测。

系统只输出概率、区间、评分和风险等级，不输出确定性预测。

## 1. 安装

建议使用 Python 3.10 或更高版本。

```bash
cd stock_ai_system
pip install -r requirements.txt
```

## 2. 运行

```bash
streamlit run app.py
```

浏览器打开 Streamlit 显示的本地地址，一般是：

```text
http://localhost:8501
```

## 3. 如何添加自选股

有两种方式：

- 首页左侧边栏快速添加股票代码；
- 进入“自选股管理”页面，添加股票代码，并设置持仓数量、成本价、手动现价、可卖数量、最大单次操作金额、单日最大做T次数和提醒阈值。

手动现价是可选项，公开行情接口不可用时会作为兜底价格。普通 A 股为 T+1 制度，做T模型只基于已有底仓和可卖数量。今日新买入数量不会计入可卖数量。

## 4. 如何查看低位区间

进入“个股详情”页面，选择自选股或输入股票代码。

系统会显示：

- 今日第一低位区；
- 今日第二低位区；
- 今日极限低位区；
- 当前价距离低位区百分比；
- 今日再创新低概率；
- 跌破第一/第二低位区概率；
- 明日惯性低开概率。

低位区间参考昨日低点、VWAP、MA5、MA10、MA20、ATR、布林带下轨、近期平台支撑和市场弱势修正。

## 5. 如何查看做T建议

进入“做T盯盘”页面。

系统会显示：

- 今日低吸区；
- 今日高抛区；
- 正T建议；
- 反T建议；
- 建议做T比例；
- 建议买入金额；
- 建议卖出金额；
- 止损线；
- 止盈线；
- 做T评分；
- 是否禁止做T；
- 今日已操作次数。

做T评分分为：

- 75分以上：可执行做T；
- 60-75：小仓试探；
- 45-60：观察；
- 45以下：不建议做T；
- 30以下：禁止做T。

## 5.0 如何查看高位/最高价区间

进入“首页总览”“个股详情”或“做T私人管家”页面。

系统会显示：

- 今日预估最高价区间；
- 正常反弹高位区；
- 强势冲高区；
- 极限高位观察区；
- 当前价距离高位区百分比；
- 今日再创新高概率；
- 突破第一/第二高位区概率；
- 明日惯性高开概率；
- 高位模型置信度。

高位区间参考昨日高点、VWAP、MA5、MA10、ATR、布林带上轨、近期平台压力、量比、分时位置和市场强弱修正。该模块只输出概率和区间，不代表绝对最高点。

## 5.0.1 如何查看未来一小时最高价预测

进入“个股详情”或“做T私人管家”的单股精细盯盘模式。系统会显示：

- 从最后一根已完成分钟线起，未来60个交易分钟的预估最高价；
- 预估最高价概率区间；
- 相对当前价的预期上行幅度；
- 突破截至当前今日高点的概率；
- 模型置信度、预测窗口、历史样本和有效相似样本。

模型按A股交易时间计算，午间休市不计入60分钟；若距离15:00收盘不足60个交易分钟，窗口会缩短到当日收盘。模型使用15/30分钟动量、实现波动率、近期振幅、价格区间位置、VWAP偏离、量能及时段，并在历史5分钟数据可用时采用无未来数据泄漏的相似时段校准；样本不足时退化为ATR与实现波动率区间。

“回测验证”页面提供未来一小时高点回测，展示区间覆盖率、绝对误差、预测偏差和突破概率Brier分数。短时预测是概率参考，不会自动触发买卖或改变做T数量。

## 5.1 如何使用做T私人管家

“做T盯盘”页面顶部就是私人管家。系统会实时生成：

- 当前管家信号：低吸区触发、高抛区触发、强观察、仅观察等；
- 做T判断：可评估正T、可评估反T、等待触发、禁止做T等；
- 当前建议操作；
- 今日最低价概率判断和判断依据；
- 今日最高价概率判断和判断依据；
- 实时提醒；
- 低吸观察价、可买股数、预计金额；
- 高抛观察价、可卖股数、预计金额；
- 何时进：进入低吸区、分时不继续放量破位、风险评分可控时才评估；
- 何时出：进入高抛区、接近预估最高区、触及止盈观察线或反T触发区时才评估；
- 止损观察线、止盈观察线和今日剩余做T次数。

页面支持两种模式：

- 单股精细盯盘：启用分钟K、VWAP和更细做T解释；
- 全自选快扫：扫描全部自选股，适合手机端快速看哪只股票进入低吸/高抛观察区。

侧边栏可以开启自动刷新。免费公开行情存在延迟、限流和接口波动，自动刷新结果只作为概率区间和风险观察，不代表确定买卖点。

## 6. 如何查看潜力股榜单

进入“每日潜力股筛选”页面。

第一版股票池来源：

- 用户自选股；
- 手动导入股票池。

页面会输出：

- 短线潜力榜；
- 中期潜力榜；
- 长期潜力榜；
- 不适合买入但值得观察的低吸观察列表；
- 风险较高应剔除列表；
- 潜力股提醒。

综合评分计算方式：

```text
综合评分 = 短线评分 × 30% + 中期评分 × 35% + 长期评分 × 35%
```

系统同时标记：

- 短线机会型；
- 中期趋势型；
- 长期成长型；
- 高风险题材型；
- 低吸观察型；
- 不建议参与型。

## 7. 如何记录卖出并触发接回提醒

进入“卖出后接回提醒”页面，录入：

- 股票代码；
- 卖出价格；
- 卖出金额；
- 卖出日期；
- 备注。

系统根据当前价格相对卖出价的回调幅度输出：

- 回调约5%：第一笔接回观察提醒；
- 回调8%-10%：第二笔接回观察提醒；
- 回调12%-15%：第三笔接回观察提醒；
- 如果卖出后不跌反涨：提示不要追高，等待新的低吸区。

## 8. 回测

进入“回测验证”页面。

第一版支持：

- 低位区间触达率回测；
- 做T策略简化胜率回测；
- 每日短线评分Top N回测；
- 次日、未来3日、未来5日涨跌幅；
- 胜率；
- 平均收益；
- 最大回撤；
- 盈亏比；
- 连续失败次数；
- 评分超过70、75、80时的表现差异。

第一版回测未计入真实滑点、手续费、涨跌停成交约束和逐笔成交约束。

## 9. 数据源限制

第一版使用 AKShare 的公开数据接口。公开数据可能存在延迟、缺失、字段调整、接口不可用等情况。

当前版本中，真实 Level-2、大单资金、主动买卖盘、企业微信提醒、机构席位、完整龙虎榜、估值历史分位、股东人数变化、机构/基金持仓变化等为预留接口或基础代理评分。

主力行为评分在第一版中不是直接的大单资金结论，而是使用成交量、量比、换手率、VWAP、分时结构、尾盘走势和相对板块强弱做代理评分。

## 10. 风险提示

本系统只做量化概率分析，不构成投资建议，股市有风险，操作由用户自行承担。
